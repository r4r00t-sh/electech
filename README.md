# ElecTech MEP Corporate Website

Production Next.js 15 site for **ElecTech Electromechanical Works LLC** (ElecTech MEP) — Dubai MEP and fire safety contractor.

## Quick start

```bash
npm install
cp .env.example .env.local
npm run dev
```
