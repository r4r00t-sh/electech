# ElecTech MEP Style Guide

## Brand

- **Name:** ElecTech MEP  
- **Legal:** ElecTech Electromechanical Works LLC  
- **Logo:** `/public/images/brand/electech-logo.png` (real asset from electechmep.com)  
- **Tone:** Confident, professional, reassuring. Short plain sentences.

## Colour (sampled from logo)

| Token | Hex | Use |
|---|---|---|
| Navy (primary) | `#1E1B5E` | Headers, dark sections, footer base |
| Navy deep | `#14123F` | Footer / hero depth |
| Green (accent) | `#0A8A45` | CTAs and highlights only |
| Mist | `#F3F4F6` | Alternating section backgrounds |
| Slate dark | `#1F2937` | Body text on white |
| White | `#FFFFFF` | Default page background / header |

## Typography

- **Headings:** Plus Jakarta Sans — large, heavy, tight tracking  
- **Body:** Inter — dark slate, not pale grey  
- One H1 per page. Spacing on an 8px scale.

## Layout

- Max-width **1280px**  
- Card radius **6px**; thin borders; flat surfaces over soft floating cards  
- Image-led heroes with navy gradient overlays  
- Solutions: asymmetric grid (1 large + 4 smaller)  
- Eyebrow labels: use sparingly (≤2 per page)
